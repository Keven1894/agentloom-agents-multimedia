**Date Distilled**: 2026-09-08  

## Purpose

为Meta广告账户搭建整合型Campaign Structure

## Preconditions

- 已明确真实Business Objective，例如购买数量、Purchase Conversion Value或Qualified Lead。
- 已准备覆盖拉新、信任建立和转化收割阶段的多样化素材。
- 确认是否存在必须独立管理的国家、市场或产品差异。
- 能够查看Campaign、Ad Set、Ads层级及其转化数据。

## Steps

### 确认是否需要按市场或产品拆分
- Anchor: [07:23](https://www.youtube.com/watch?v=EtU45PsaL1M&t=443s)
```bash
检查业务是否存在不同国家、市场或需要独立优化的大量产品；没有明确业务边界时，不要仅因预算或账户规模增加Campaign。
```

### 根据真实业务目标创建Campaign
- Anchor: [06:40](https://www.youtube.com/watch?v=EtU45PsaL1M&t=400s)
```bash
在Campaign层级选择真实Business Objective；购买数量使用Conversion Volume方向，高价值购买使用Conversion Value方向，本地获客业务使用Lead目标。
```

### 选择CBO作为预算分配方式
- Anchor: [07:02](https://www.youtube.com/watch?v=EtU45PsaL1M&t=422s)
```bash
在One Campaign场景中启用CBO，让Campaign在统一环境中分配预算。
```

### 建立一个主要Ad Set
- Anchor: [06:00](https://www.youtube.com/watch?v=EtU45PsaL1M&t=360s)
```bash
对大多数单产品或新产品业务建立One Ad Set，不按Top Funnel、Middle Funnel和Bottom Funnel拆分多个广告组。
```

### 将多样化Ads集中到Ad Set
- Anchor: [10:59](https://www.youtube.com/watch?v=EtU45PsaL1M&t=659s)
```bash
把图片、视频、Primary Text和Headline组合成多个Ads，并将覆盖不同漏斗阶段的素材放进同一个Ad Set。
```

### 为新素材设计测试机制
- Anchor: [04:57](https://www.youtube.com/watch?v=EtU45PsaL1M&t=297s)
```bash
让新Ads获得独立Signal，同时避免破坏既有Winning Ads Team；测试后记录账户整体变化及其积极或消极影响。
```

### 集中观察学习和转化信号
- Anchor: [11:20](https://www.youtube.com/watch?v=EtU45PsaL1M&t=680s)
```bash
在同一个Ad Set中观察素材、转化量和学习状态，避免将有限数据分散到多个组。
```

### 对多产品业务按产品建立Ad Set
- Anchor: [12:03](https://www.youtube.com/watch?v=EtU45PsaL1M&t=723s)
```bash
如果业务有大量产品且优化购买价值，在同一Campaign和CBO下为每个产品建立一个Ad Set，每个产品Ad Set放置多个Ads。
```

### 依据转化密度而非预算决定是否扩展结构
- Anchor: [12:48](https://www.youtube.com/watch?v=EtU45PsaL1M&t=768s)
```bash
比较预算带来的实际Conversion数量；只有在产品、市场或数据量确实支持独立学习时，才考虑增加Ad Set或结构边界。
```

### 以Creative Strategy作为后续优化重点
- Anchor: [01:45](https://www.youtube.com/watch?v=EtU45PsaL1M&t=105s)
```bash
结构稳定后，优先增加Creative Diversity和优化创意策略，而不是继续增加Campaign数量。
```

## Verification

Campaign层级能清楚表达唯一或明确的Business Objective。
大多数单产品业务已实现One Campaign、One Ad Set、多个Ads和CBO。
不同国家、市场或产品的拆分都有可解释的业务原因。
新Ads能够获得测试信号，同时既有Creative Team没有被无意义地拆散。
转化和学习数据集中在同一Ad Set或合理的产品Ad Set中。
测试后能够明确判断账户发生了什么变化，并据此制定下一轮Creative测试。
