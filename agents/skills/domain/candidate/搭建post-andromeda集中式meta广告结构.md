**Date Distilled**: 2026-09-08  

## Purpose

搭建Post-Andromeda集中式Meta广告结构

## Preconditions

- 已明确最终Business Objective，例如Purchase、Conversion Value或Qualified Lead。
- 已确认业务不需要按国家、市场或产品建立独立优化目标。
- 账户能够提供足够的预算和转化信号支持机器学习。
- 已准备覆盖不同漏斗阶段和不同表达角度的多样化Creative。

## Steps

### 确认是否需要拆分Campaign
- Anchor: [10:18](https://www.youtube.com/watch?v=EtU45PsaL1M&t=618s)
```bash
检查业务是否存在不同国家、市场或产品目标；若不存在，默认采用一个Campaign。
```

### 设置Campaign业务目标
- Anchor: [06:44](https://www.youtube.com/watch?v=EtU45PsaL1M&t=404s)
```bash
根据真实业务目标选择Campaign Objective；购买数量选择Maximized Conversion Volume，购买价值选择Conversion Value，Qualified Lead选择Lead。
```

### 启用CBO
- Anchor: [07:05](https://www.youtube.com/watch?v=EtU45PsaL1M&t=425s)
```bash
在Campaign层级启用CBO，让预算在集中结构中由Meta进行分配。
```

### 建立单一Ad Set
- Anchor: [06:02](https://www.youtube.com/watch?v=EtU45PsaL1M&t=362s)
```bash
在Campaign下建立一个Ad Set，避免按Top Funnel、Middle Funnel、Bottom Funnel或过细受众进行拆分。
```

### 将多样化Ads放入同一Ad Set
- Anchor: [06:23](https://www.youtube.com/watch?v=EtU45PsaL1M&t=383s)
```bash
把图片、视频、Primary Text和Headline组合成多个Ads，并将其全部放入同一个Ad Set。
```

### 覆盖不同漏斗任务
- Anchor: [04:11](https://www.youtube.com/watch?v=EtU45PsaL1M&t=251s)
```bash
准备分别用于拉新、建立信任和转化收割的素材，让同一Creative Team覆盖不同客户阶段。
```

### 集中机器学习信号
- Anchor: [11:20](https://www.youtube.com/watch?v=EtU45PsaL1M&t=680s)
```bash
让所有主要Ads在同一Ad Set中获得转化数据，减少数据分散并帮助Meta更快判断素材与受众的匹配关系。
```

### 按业务例外进行拆分
- Anchor: [12:24](https://www.youtube.com/watch?v=EtU45PsaL1M&t=744s)
```bash
如果存在多个产品且需要分别优化，可在同一Campaign下按产品建立Ad Set；如果存在不同国家或市场，可按市场拆分Campaign。
```

### 评估预算与转化量
- Anchor: [13:04](https://www.youtube.com/watch?v=EtU45PsaL1M&t=784s)
```bash
检查每日预算能带来的Conversion数量；转化量不足时继续保持集中结构，不要通过增加Ad Set来制造更多分组。
```

### 通过测试观察结构变化
- Anchor: [04:59](https://www.youtube.com/watch?v=EtU45PsaL1M&t=299s)
```bash
建立Testing Ads，观察其对整个账户的积极或消极影响，并根据结果设计下一轮测试。
```

## Verification

确认Campaign目标与真实业务目标一致；确认默认结构为One Campaign、One Ad Set、多个多样化Ads；检查是否因国家、市场或产品差异而存在合理拆分；观察学习阶段、转化量、ROAS和素材表现是否趋于稳定，并确保测试结果能够说明变化来源。
