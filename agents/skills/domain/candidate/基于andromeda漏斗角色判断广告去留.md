## Purpose

基于Andromeda漏斗角色判断广告去留

## Preconditions

- 拥有Meta广告账户的广告级数据。
- 至少能查看Spend、Cost per Result、Purchase、ROAS和Conversion Value。
- 账户中存在多种广告创意，能够覆盖不同用户画像或认知阶段。

## Steps

### 识别传统指标上的赢家与输家
- Anchor: [03:10](https://www.youtube.com/watch?v=VFjup6AbQOM&t=190s)
```bash
按Spend、Cost per Result、Purchase和ROAS整理广告，但先将高ROAS低Spend广告标为候选Winning Ad，将高Spend低ROAS广告标为候选Loser Ad，不立即执行关闭。
```

### 为广告推断漏斗角色
- Anchor: [08:43](https://www.youtube.com/watch?v=VFjup6AbQOM&t=523s)
```bash
检查广告是否更可能承担Top Funnel触达教育、Middle Funnel考虑或Bottom Funnel转化角色；高Spend低直接ROAS的广告优先作为Top Funnel候选。
```

### 用账户整体结果做最终决策
- Anchor: [10:38](https://www.youtube.com/watch?v=VFjup6AbQOM&t=638s)
```bash
观察广告组合及账户层面的Conversion Value、Purchase和长期ROAS；保留能够补充用户教育和转化链路的广告，避免只复制单条高ROAS广告或直接关闭单条低ROAS广告。
```

## Verification

验证账户是否形成覆盖不同认知阶段的Creative Team，并持续观察整体Conversion Value、Purchase和ROAS是否改善；若关闭上层广告后下层转化、ROAS或新客供给逐步下降，说明该广告可能承担了上层漏斗职能。
