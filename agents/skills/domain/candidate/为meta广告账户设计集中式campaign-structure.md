## Purpose

为Meta广告账户设计集中式Campaign Structure

## Preconditions

- 明确真实业务目标，例如购买数量、购买价值或Qualified Lead。
- 确认是否存在必须独立管理的国家、市场或产品。
- 评估预算与每日转化量是否足以支持多个Ad Set。
- 准备覆盖不同客户阶段和不同信息角度的多样化素材。

## Steps

### 确定是否需要拆分Campaign
- Anchor: [10:17](https://www.youtube.com/watch?v=EtU45PsaL1M&t=617s)
```bash
仅在国家或市场、产品线或明确业务目标不同的情况下拆分Campaign；否则优先保留一个Campaign。
```

### 设置Campaign Objective
- Anchor: [06:40](https://www.youtube.com/watch?v=EtU45PsaL1M&t=400s)
```bash
购买数量选择Maximize Conversion Volume；购买价值选择Maximize Conversion Value；本地获客业务选择Lead。
```

### 启用CBO
- Anchor: [10:38](https://www.youtube.com/watch?v=EtU45PsaL1M&t=638s)
```bash
在One Campaign结构中使用CBO，让预算在Campaign层级集中分配。
```

### 建立一个核心Ad Set
- Anchor: [06:00](https://www.youtube.com/watch?v=EtU45PsaL1M&t=360s)
```bash
在大多数业务中建立One Ad Set，将学习信号集中在同一个广告组内。
```

### 将多样化Ads集中到Ad Set
- Anchor: [10:59](https://www.youtube.com/watch?v=EtU45PsaL1M&t=659s)
```bash
把图片、视频、Primary Text和Headline组合成多个Ads，并覆盖Top Funnel、Middle Funnel和Bottom Funnel需求。
```

### 针对多产品业务按产品拆分Ad Set
- Anchor: [12:27](https://www.youtube.com/watch?v=EtU45PsaL1M&t=747s)
```bash
若产品差异明显且转化量足够，在同一Campaign下为每个产品建立一个Ad Set，每个Ad Set放置多个广告。
```

### 评估学习数据是否支持拆分
- Anchor: [12:48](https://www.youtube.com/watch?v=EtU45PsaL1M&t=768s)
```bash
比较每个Campaign或Ad Set的预算与转化量；若转化量不足，重新整合结构，避免信号过度分散。
```

### 通过测试观察结构变化
- Anchor: [04:57](https://www.youtube.com/watch?v=EtU45PsaL1M&t=297s)
```bash
建立测试广告并记录其对整体账户的积极或消极变化，再据此决定下一轮测试。
```

## Verification

检查Campaign是否围绕单一明确业务目标，是否使用CBO，是否在不必要的情况下避免国家、漏斗、Remarketing或受众的重复拆分；确认Ad Set获得足够转化信号，学习期和投放稳定性改善，并能清晰判断新测试对整体账户的影响。
